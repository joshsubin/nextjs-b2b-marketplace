# Next.js B2B Marketplace Demo

An independently built maritime-themed B2B marketplace UI using fictional vendors and sample data.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Included
- Responsive marketplace landing page
- Fictional provider cards
- Category, location and inquiry UI foundation

## Planned extensions
- Search and filters
- Company registration and profiles
- API-backed listings
- Secure messaging and subscription entitlements
- Database persistence and automated tests

This is a portfolio demo, not the Seartify production application. No client code or customer data is included.
